🏡 Wanderlust – Airbnb Clone
Wanderlust is a full-stack web application inspired by Airbnb. It allows users to create, explore, and manage property listings with authentication and image uploads. Built using Node.js, Express, MongoDB, and EJS templates, Wanderlust provides a smooth experience for learning full-stack development.
________________________________________
✨ Features
•	🔍 Browse and search property listings
•	🖼️ Upload property images (Cloudinary integration)
•	👤 User authentication & authorization (Passport.js)
•	✏️ Create, edit, and delete listings
•	💬 Flash messages & validation for better UX
________________________________________
🔧 Tech Stack
•	Backend: Node.js, Express.js, MongoDB, Mongoose
•	Frontend: EJS Templates, Bootstrap/CSS
•	Authentication: Passport.js (Local strategy)
•	File Storage: Cloudinary
________________________________________
🚀 Project Goal
Wanderlust is built as a learning project to understand full-stack web development concepts including authentication, database modeling, RESTful routes, and deployment.
