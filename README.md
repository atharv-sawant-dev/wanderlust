<h1>🏡 Wanderlust – Airbnb Clone</h1>
<p>Wanderlust is a full-stack web application inspired by Airbnb. It allows users to create, explore, and manage property listings with authentication and image uploads. Built using Node.js, Express, MongoDB, and EJS templates, Wanderlust provides a smooth experience for learning full-stack development.</p>

<hr>

<h2>✨ Features</h2>
<ul>
  <li>🔍 Browse and search property listings</li>
  <li>🖼️ Upload property images (Cloudinary integration)</li>
  <li>🧑‍🤝‍🧑 User authentication & authorization (Passport.js)</li>
  <li>✏️ Create, edit, and delete listings</li>
  <li>💬 Flash messages & validation for better UX</li>
</ul>

<hr>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li>Backend: Node.js, Express.js, MongoDB, Mongoose</li>
  <li>Frontend: EJS Templates, Bootstrap/CSS</li>
  <li>Authentication: Passport.js (Local strategy)</li>
  <li>File Storage: Cloudinary</li>
</ul>

<hr>

<h2>🚀 Project Goal</h2>
<p>Wanderlust is built as a learning project to understand full-stack web development concepts including authentication, database modeling, RESTful routes, and deployment.</p>
